Let Claude set it up

  1. 1

    Get the Claude app

    Sign in, then click Code at the top left. You need a paid plan, Pro or above.

    Download Claude
  2. 2

    Copy this, paste it, press Enter

    Click Allow when it asks.

    First it asks if you want HiveMind in the terminal, where it works better and shows its dashboard. Then it installs or updates what HiveMind needs, asking before each install, and tells you your PowerWorld version. It never opens or changes your PowerWorld cases.

    Read the request first 
    Set up PoWerHiveMind on this computer for me. Ask me before you install anything, and explain each step in plain words. After you install any program, call it by its full path, because this session won't see it on the PATH yet.

1. First ask me one question: do I want to use HiveMind in the terminal? It works better there, because the terminal shows the HiveMind dashboard: the version, my usage limits and how full the context is. If I'm not familiar with the terminal, keep me in the Claude desktop app. That works fine too. Remember my answer.
2. Install HiveMind: clone https://github.com/ChunSikPark/PoWerHiveMind into ~/.claude/skills/powerhivemind. If Git is missing, install it first.
3. Run the HiveMind setup: follow commands/powerworld-setup.md in that folder. Where it says ${CLAUDE_PLUGIN_ROOT}, use that folder. If Python is missing, don't stop: install it with "Add Python to PATH" turned on, then use the full path to python.exe. The setup installs or updates the Python packages HiveMind needs and checks that PowerWorld and the SimAuto licence work. When it offers the dashboard, use my answer from step 1 instead of asking again.
4. Tell me what the check found, including my PowerWorld version and whether HiveMind was tested on it. Do step 5 even if the check failed.
5. If I chose the terminal: install Claude Code with irm https://claude.ai/install.ps1 | iex, open a new PowerShell window, and start claude there by its full path. Tell me a browser will open once so I can sign in. If I chose the app: tell me to start a new conversation here so HiveMind loads.
  3. 3

    Check it worked

    In a new conversation, ask this trick question:

    esapp warns that the Branch field LineStatus is read-only. Can I still open a line by writing it?
    Right"Yes. It's only a warning, you can still write it." HiveMind loaded.
    Wrong"No, it's read-only." Start a new conversation and ask again.

Install it yourself

  1. 1. Install HiveMind Claude Code

    Paste into Claude Code, then load it.

    Run in the terminal. Then open /plugins, install powerhivemind, and start a new session. Not yet tested on a released Codex build.

    Install the PowerWorld knowledge base: git clone https://github.com/ChunSikPark/PoWerHiveMind ~/.claude/skills/powerhivemind
    /reload-plugins
    codex plugin marketplace add ChunSikPark/PoWerHiveMind

  2. 2. Run setup Claude Code

    Installs the Python packages and checks that PowerWorld and SimAuto can be driven from this machine.

    /powerhivemind:powerworld-setup
    Read the AGENTS.md of the powerhivemind plugin. Check whether Python is installed, install the esapp and TeamOverbyeWeather packages if they are missing, then run the preflight check.

  3. 3. Check it worked

    Trick question. "Yes, it's only a warning, you can still write it" means HiveMind loaded.

    esapp warns that the Branch field LineStatus is read-only. Can I still open a line by writing it?

Then try it on your own case

Open my case at C:\path\to\case.pwb and summarize it.
Run an N-1 contingency analysis and show me the worst violations.
Add a 138 kV line between bus 12 and bus 40 and tell me what it does to N-1.
