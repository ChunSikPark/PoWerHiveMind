Install

About fifteen minutes, and no coding. Three downloads, a few clicks, and one sentence pasted into a chat box. You need PowerWorld Simulator on this Windows computer already.

  1. Get the Claude app

    Download it, open the file it saves, and sign in. You need a paid plan (Pro or above), because the free plan doesn't include the Code tab. Install Git too, clicking through with every default. Claude uses it to fetch the kit.

    Download ClaudeDownload Git

  2. Get Python

    Run the installer, and on its first screen, tick "Add Python to PATH" before you click Install. The box is off by default, and missing it is the most common way this goes wrong.

    Download Python

  3. Open the Code tab

    In Claude, click Code at the top left. The Chat tab can't see your files. Code can, and it's where everything below happens.

  4. Paste one sentence

    Paste this into the message box and press Enter. It's a request, not a command: you're asking Claude to fetch the kit for you.

    Install the PowerWorld knowledge base: git clone https://github.com/ChunSikPark/PowerWorldHiveMind ~/.claude/skills/powerworld-hivemind

    When it's done, type this to load it:

    /reload-plugins

  5. Let it check your computer

    Type this. It installs what the kit needs and checks that PowerWorld can be driven from this machine.

    /powerworld-hivemind:powerworld-setup

    If it says SimAuto isn't licensed, that's a PowerWorld licence question for whoever manages yours, not a mistake you made.

    Use Claude Code in a terminal? Setup also offers a PWHM dashboard for your status line: the kit's version, the model, your usage limits and how full the context is. It asks first. If you already have a status line, it keeps yours and adds just the [PWHM#0.5.1] tag. The desktop app doesn't show status lines.

  6. Ask your first question

    Start with this one. The right answer is "it silently writes no file". If it says "it saves the case", type /reload-plugins and ask again.

    Without running any code, what happens if I call pw.esa.SaveCase("out.pwb")?

    Then point it at one of your own cases, in plain English:

    Open my case at C:\path\to\case.pwb and summarize it.
    Run an N-1 contingency analysis and show me the worst violations.

    You won't have to check for updates. When a new version comes out, Claude tells you at the start of a session and offers to update it.

How your AI talks to PowerWorld

You talk to the agent in plain English. The agent reaches Simulator one of two ways.

The default: one live Python session

The agent writes Python with esapp, which drives Simulator through SimAuto. It opens the case, writes changes, solves, and reads every write back, because PowerWorld reports success on writes that did nothing.

Fast, scriptable, runs in parallel. Every demo uses it. Needs the SimAuto add-on, which is licensed separately.

Aux file integration: the agent reads what PowerWorld said

Turn on one setting and Simulator watches a folder. The agent writes an .aux script and drops it in. Simulator runs it and writes back the result CSVs and its own message log for that script: records read, control adjustments, every mismatch iteration, and whether the solve succeeded.

A SimAuto call hands back only an error string, so a silent failure stays silent. Here the agent reads the log line that explains it, and you keep a script you can read and re-run.

It's slower: a dialog has to stay open, so there's no batching, and it needs a recent Simulator build.

Setup, rules and a template
  • You ask: "Add a 138 kV line between bus 12 and bus 40 and tell me what it does to N-1."
  • Without any PowerWorld licence you can still fetch and inspect weather data. It is pure Python.

Web search finds what a command does. It rarely finds that the call reports success and does nothing: on those 16 questions the web got 7 and the kit got 15.

          
The kit also needed 3.2x fewer searches per right answer.

          
The case-auditor agent and a plain model got the same audit findings for 8 cases, 3 runs each. This test ran on a build after v0.4.0, with Sonnet. A blind judge found the agent described the case correctly in 21 of 24 runs, the plain model in 10. The plain model hardly ever invents anything: on one combined check (no invented cost data, only the three severity labels, no pasted raw findings) it passed 50 of 51, the agent 51 of 51. The difference is in the call: what actually stops the study.

          
For exact argument syntax, open PowerWorld's manual instead. The kit deliberately does not publish it, so it sometimes names the right command without a signature.
